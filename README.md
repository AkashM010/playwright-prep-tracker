# Playwright Automation Revision Tracker 🚀

A focused, staged interview preparation and revision tracker for QA automation engineers.

🌐 **Live URL**: [https://akashm010.github.io/playwright-prep-tracker/](https://akashm010.github.io/playwright-prep-tracker/)

---

## 🎯 Learning Path Overview

The tracker is organized into three sequential learning phases:

1. **Phase 1: JavaScript Foundations** (9 topics)
   - Core language essentials, scoping, closures, async/await, modules, and arrays.
   - Includes a curated lesson mapping for CodeWithHarry's JavaScript course.
2. **Phase 2: TypeScript Essentials** (9 topics)
   - Type annotations, interfaces, generics, unions, OOP, and `tsconfig.json`.
3. **Phase 3: Playwright Automation & Interview Practice** (15 topics)
   - Locators, POM, fixtures, hooks, configuration, parallel runs, API testing, auth state, network mocking, and mock interview practice.

---

## ✨ Features

- **Apple-Inspired Spatial UI**:
  - 3D parallax tilt & specular cursor glare tracking on the progress panel.
  - Tactile macOS-style controls with spring compression physics.
  - Spatial Z-axis hover lift on curriculum items.
  - Fluid 3D spring pop animations on topic completion.
  - Glass-tube progress bar with dynamic specular light sheen.
- **Offline First**: All progress is automatically persisted in your browser's local storage (`standalone_js_ts_playwright_tracker_v1`).
- **AI Exam Prompts**: Every single topic includes a one-click copyable exam prompt configured with targeted testing rules for technical interview prep.
- **Export & Import**: Seamlessly backup and restore your progress across different browsers and devices via JSON.
- **Print Friendly**: Dedicated print stylesheets for physical checklist review.
